# workbench 1.0 final

个人 AI 补丁工作台。复制补丁到剪贴板，点运行，自动改文件。

## 用法

1. 把脚本复制到剪贴板
2. 点 `▶ 运行`
3. 输出框看结果（自动复制）
4. 出错点 `❓ 帮助` 查语法

## 支持块

- `=== FILE: 路径 ===` 补丁块
  - `[REPLACE] 旧 ==> 新`
  - `[REPLACE #2] 旧 ==> 新`（指定第 2 处）
  - `[DELETE] 内容`
  - `[INSERT_AFTER] 锚点 ==> 内容`
  - `[INSERT_BEFORE] 锚点 ==> 内容`
- `=== READ ===` 读文件（默认 200 行）
- `=== CMD ===` 白名单命令
- `=== PS ===` PowerShell 脚本
- `=== GIT ===` git 子命令

## 数据位置

- 全部运行时数据在 `.wb/`
- `lastgood.py` 是回滚备份
- `backups/` 是撤销用备份（保留最近 20 次）

## 备份

拷走 `workbench.py` + `.wb/` 即可。
